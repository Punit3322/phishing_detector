Dataset & Feature Engineering Pipeline

Overview of how raw email text is transformed into numerical feature vectors for Scikit-Learn.

1

Text Preprocessing

Lowercasing text, stripping HTML tags using BeautifulSoup regex, removing English stopwords, and applying Porter Stemmer to normalize word variations (e.g., "verifying", "verify" -> "verifi").

2

TF-IDF Vectorization

Term Frequency-Inverse Document Frequency converts text documents into sparse numerical matrices with n-gram range (1, 2) and max_features=5,000 to capture word pairs like "account suspended".

3

Heuristic Feature Fusion

Additional engineered metadata features are appended: link count, presence of IP addresses in URLs, uppercase ratio in subject lines, and trigger keyword counts (e.g., "urgent", "password", "verify").

Python Scikit-Learn Implementation Code

Complete standalone Python script to train and serialize the phishing detection model.

train_phishing_detector.py Python 3.10+ / Scikit-Learn 
import pandas as pd
import numpy as np
from sklearn.model_selection import train_test_split
from sklearn.feature_extraction.text import TfidfVectorizer
from sklearn.linear_model import LogisticRegression
from sklearn.metrics import classification_report, confusion_matrix, accuracy_score
import joblib

# 1. Load Dataset (CSV containing 'text' and 'label' columns where 1=phish, 0=legit)
print("[+] Loading phishing dataset...")
df = pd.read_csv("phishing_emails.csv")

# 2. Train / Test Split (80% train, 20% test)
X_train, X_test, y_train, y_test = train_test_split(
    df['text'], df['label'], test_size=0.2, random_state=42, stratify=df['label']
)

# 3. TF-IDF Feature Extraction (Unigrams & Bigrams)
print("[+] Fitting TF-IDF Vectorizer...")
vectorizer = TfidfVectorizer(max_features=5000, ngram_range=(1, 2), stop_words='english')
X_train_tfidf = vectorizer.fit_transform(X_train)
X_test_tfidf = vectorizer.transform(X_test)

# 4. Train Logistic Regression Classifier
print("[+] Training Logistic Regression Model...")
model = LogisticRegression(C=1.0, max_iter=1000, random_state=42)
model.fit(X_train_tfidf, y_train)

# 5. Evaluate Model Performance
y_pred = model.predict(X_test_tfidf)
print("\n--- Model Evaluation ---")
print(f"Accuracy:  {accuracy_score(y_test, y_pred) * 100:.2f}%")
print(f"Confusion Matrix:\n{confusion_matrix(y_test, y_pred)}")
print(f"\nClassification Report:\n{classification_report(y_test, y_pred)}")

# 6. Save Model and Vectorizer for Production Deployment
joblib.dump(model, "phishing_model.pkl")
joblib.dump(vectorizer, "tfidf_vectorizer.pkl")
print("[+] Model and vectorizer successfully serialized to disk.")
